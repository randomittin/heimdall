## 2026-08-22T15:30:28Z — [COMMUNICATION] docs(prompt): stop telling the orchestrator no hook emits metrics — one now does

The embedded operating prompt claimed "call it yourself, no hook does". As of 6e8ad61
a SubagentStop hook emits a task-outcome record per spawned agent, so that instruction
was false the moment it shipped — exactly the doc-drift this repo keeps getting bitten
by, and worse than useless here because it tells the orchestrator to duplicate work the
machine now does.

Corrected to say what is true and what is still needed by hand: the hook supplies the
baseline, and an orchestrator adds only what a hook cannot truthfully observe — the task
type, and whether acceptance criteria passed on the FIRST try at this tier. Carries the
warning that matters more than the field: never guess those values. A fabricated outcome
poisons the exact routing decision the data exists to inform, and a sparse record beats
a corrupted one.

Deliberately left intact: "nothing consumes routing-overrides.json yet, so model routing
does not adjust on its own." Verified still true — heimdall-self-improve writes it and
only it and bin/lib/dream_data.py read it; nothing in the routing decision path does.
Correcting a stale half of a sentence is not licence to overstate the other half.
