## 2026-08-22T14:15:10Z — [COMMUNICATION] feat(hooks): wire PostToolUse:Bash -> heimdall-journal so commits journal themselves

The owner asked, verbatim, for hmd to "write summaries while implementing
and communicating to user and save these in a journal like code system",
and separately laid down the standing verdict that "by nature, hmd should
use these skills on autopilot and not by an external invocation... coz
then what's the point of hmd?!". bin/heimdall-journal (deb83b2) shipped a
complete add/today/tail/grep/path CLI but zero mechanical trigger -- the
only path to it was a sentence in skills/heimdall/SKILL.md, exactly the
kind of prose-only mechanism this repo has already measured a 26x adoption
gap against (130 parallelism-tracker records vs 5 heimdall-metric records
over 83 days, see bin/heimdall-metric-hook).

bin/heimdall-journal-hook adds a `commit` subcommand, wired to a new
PostToolUse:Bash block in hooks/hooks.json. On every Bash call it cheaply
no-ops unless the executed command is git-commit-shaped (same regex as the
PreToolUse:Bash git-guard chain, hooks/hooks.json:27). When it is, it
compares real HEAD against a branch-qualified git-config marker
(heimdall.journalLastCommit-<branch>, not a single flat key -- this repo
runs many concurrent worktrees of the same clone sharing one
.git/config, so a flat key would let one worktree's commit clobber
another's dedup state) to confirm a NEW commit actually landed, rather
than trusting a self-reported exit code. Only then does it call
`heimdall-journal add communication <subject> --body <body> --evidence
"commit <sha>"`, falling back to the subject as the body when the commit
carries no body (heimdall-journal requires a non-empty body by its own
design). The dedup marker is claimed before the write is attempted, not
after, so a crash loses at most one entry and never double-writes one --
a journal is bookkeeping, never a correctness gate, same standard as
bin/heimdall-wip-commit and bin/heimdall-metric-hook.

heimdall-journal's own add/today/tail/grep/path interface is unmodified
and unredesigned; this is purely a caller.

test/heimdall-journal-hook.test.sh (22 assertions): hooks.json shape and
matcher, real-commit -> real journal entry with correct subject/SHA,
empty-body fallback, non-empty-body preservation verbatim, dedup at an
unchanged HEAD, non-commit commands never touching the journal, and four
fail-open cases (malformed JSON, empty stdin, missing binary, non-git
target) all exiting 0 with nothing written. Keep-green suites still pass:
gate-echo-parser-guard.test.sh 7/7, sessionstart-quiet.test.sh 27/27,
heimdall-init.test.sh 37/37.
