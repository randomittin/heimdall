## 2026-09-20T13:53:35Z — [COMMUNICATION] feat(ui): POST /api/send -- the companion app queues a message for the running session

Adds the companion -> session write path behind the same loopback + Host
allowlist (403) + per-launch token (401) gate as every other hmd ui route:

  - 415 when Content-Type is not application/json
  - 413 when the request body exceeds 4096 bytes
  - 400 on malformed JSON or a missing/non-string `text` field
  - 422 {"error":"empty"|"too-long"|"secret-shaped"} on validation failure
    (empty after strip, >2000 chars, or secret_shaped() match)
  - 202 {"id": <uuid4>, "queued": <n>} on success

Storage: bin/lib/companion_ui_inbox.py owns the contract (validation, secret
scrub, atomic append/pop under one flock) at <repo>/.heimdall/ui/inbox.jsonl,
delivered messages archived to <repo>/.heimdall/ui/inbox-delivered.jsonl.
Both sentinels/hmd-ui.py's POST handler and the new `hmd ui inbox ls|pop|peek`
CLI import this single module so writer and reader can't drift.

/api/state gains an additive top-level "inbox": {"pending": <n>} key.

test/heimdall-ui-inbox.test.sh: 27/27 passing. heimdall-ui.test.sh (30/30)
and heimdall-ui-panels.test.sh (57/57) still pass unchanged.

## 2026-09-20T13:54:46Z — [COMMUNICATION] feat(ui): heimdall-inbox-deliver -- drain the companion inbox into the session (stop|prompt|tmux|status)

Delivers messages queued by the hmd companion app (<repo>/.heimdall/ui/inbox.jsonl,
POST /api/send) into a running Claude Code session via three injection points:

  - stop     Stop-hook contract: pops a queued message and prints
             {"decision":"block","reason":"<text>"}. If the queue is empty but
             the turn ended on a question, long-polls every 2s for up to
             HMD_INBOX_WAIT_S (default 240) so a same-session phone reply
             still lands on this turn. Loop-guarded on stop_hook_active.
  - tmux     Best-effort `tmux send-keys` delivery into a configured pane.
  - prompt   UserPromptSubmit fallback: folds pending messages into
             hookSpecificOutput.additionalContext.
  - status   Reports {"pending": n, "waiting": bool}, never pops.

Imports bin/lib/companion_ui_inbox.py when present (append/list_pending/
pop_all/peek), falling back to an inline reimplementation of the same
file protocol so the tool and its own tests work standalone. Every mode
exits 0 -- a delivery bug must never block a Stop/UserPromptSubmit turn.

test/heimdall-inbox-deliver.test.sh: 36/36 passing.

Not wired yet: no hooks/hooks.json Stop/UserPromptSubmit entries (that file
is locked/registry-governed) and no one-line `hmd inbox` dispatch entry in
bin/heimdall (its `ui)` case arm is a 5-line block, not a one-liner, so
wiring was left out per instructions). Invoke by path until that lands.
