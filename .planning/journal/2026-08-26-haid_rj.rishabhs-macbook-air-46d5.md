## 2026-08-26T03:02:23Z — [COMMUNICATION] fix(fallback): empty the built-in ToS deny list, keep the operator override

BUILTIN_TOS_FLAGGED_PROVIDERS held ~30 entries — mistral, cohere, vertex,
nvidia, cerebras, huggingface, openrouter among them — so
target_provider_allowed could never pass for any realistic provider and the
fallback could not route AT ALL. The feature was inert, and its suite was green
because the tests used fixture names rather than real ones.

Owner decision (2026-08-26): empty it. The operator turns fallback on
EXPLICITLY — `set on|auto|switch` is a deliberate act hmd never performs itself
— and has accepted the data-handling risk. A built-in list overriding that is
hmd deciding for the operator, and here it blocked the feature entirely.

WHAT THE OLD LIST GOT WRONG: it was sourced from the 2026-08-23 assessment's
table of OmniRoute's free-tier POOLED-CREDENTIAL proxy exposure, and applied
verbatim to providers themselves. Those are different things. Using the
operator's OWN key for a direct pinned request against Mistral's first-party
API is not a ToS conflict — the credential-isolation audit specifically found
that shape to be the cleanest available.

THE MECHANISM SURVIVES, ONLY THE DEFAULT CHANGED. tos_flagged_providers in the
operator's config still denies whatever they list; proven by tests 10 and 31,
which previously relied on built-in denial and now assert the same denial via
the override. An empty target_provider still FAILS — that is a completeness
check, not policy. The keyless/weakest-terms note still prints: informing
without blocking is exactly the ask.

THIS IS NOT WHAT PROTECTED THE ANTHROPIC ACCOUNT, and the tests now prove it
rather than asserting it. New cases 46 and 47: with the deny list EMPTY and
target_provider newly allowed, a live `claude` row in OmniRoute's DB still
yields REFUSE — under `auto` and under `switch` alike. tier1_credential_absent,
anthropic_model_pinned, prefer_claude_code_flag_off and no_delegated_sidecar
are untouched and still gating; none of them ever referenced the deny-list set.

Verified end to end by hand after the carry — the first time the whole chain
has produced a route: target_provider=mistral, Tier-1 verified absent, session
verdict crossed -> VERDICT: ROUTE, exit 0.
