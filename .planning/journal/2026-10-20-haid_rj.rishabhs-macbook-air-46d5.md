## 2026-10-20T23:05:39Z — [COMMUNICATION] feat(hooks): deny a full sweep the records already answer (sweep guard)

bin/heimdall-precheck-bash now asks bin/lib/hmd_sweep_guard.py, after the CI waste guard and the disk floor, whether a command is a FULL test/run-all.sh (no --failed, --since-green, --filter, --dry-run) that the repo's own records already answer. It denies one when a sweep is running (sweep.lock plus a live pid), when the last receipt is red or aborted and its head_sha is HEAD or an ancestor of it, or when a green full receipt already covers HEAD with a clean tree.

--failed, --filter, --since-green, single suites and --cold while the cache is cold anyway (the salt changed) go through. HMD_SWEEP_ALLOW=1 in the hook's own environment lifts the guard. It finds a real run with the kill guard's lexer (text that only mentions run-all.sh is no run), takes the repo from the script's own location, and fails open with one stderr line on a missing or garbled receipt, a git failure or a timeout.

Test: test/sweep-guard.test.sh. CLAUDE.md (Release convergence) and CHANGELOG [Unreleased] name the guard.

## 2026-10-20T23:08:20Z — [COMMUNICATION] feat(conformance): catch the fix -> finding -> fix loop (full-sweep-after-red, fix-chain, spawn-time warning)

bin/heimdall-conformance gains two transcript gates, both in all. full-sweep-after-red fails a full run-all.sh (no --failed/--since-green/--filter) started after a red sweep with no green between; a red is a verdict (a foreground Exit code N or a failed background task), so a refused call, a TaskStop or a killed task is not one. fix-chain fails more than HMD_FIX_CHAIN_MAX (default 3) consecutive Agent spawns whose description or prompt names a fix and a review or security finding inside one release cycle (a release tag or release/ship.sh ends the cycle, an unrelated spawn ends the run), naming the spawns.

bin/heimdall-precheck-agent warns on stderr (exit 0, never a deny) when a spawn would be past the limit for the session: per-session counter under HEIMDALL_HOME/fix-chain, a glob pre-filter so other spawns pay nothing, HMD_FIX_CHAIN_ALLOW=1 silences it, fail-open everywhere. bin/lib/hmd_fix_chain.sh is the one definition of a finding-fix spawn, shared by both. Tests: test/protocol-conformance.test.sh (P, Q, M23-M37) and a new test/agent-fix-chain.test.sh (one suite per hook section, like agent-inproc-cap and agent-ctxgate-fence).
