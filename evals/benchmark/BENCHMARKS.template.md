## Metric Definitions

| Metric | Definition |
| --- | --- |
| Tokens total | `.usage.input_tokens + .usage.cache_read_input_tokens + .usage.cache_creation_input_tokens + .usage.output_tokens` from `claude --output-format json` |
| Tokens by role | in = raw input; out = output; cr = cache read; cw = cache write — parsed from `.usage.*` |
| Wall time | `date +%s%N` monotonic ns clock around the CLI invocation; seconds (2 d.p.) |
| Tests passing | Count of `verify[]` oracle commands that exit 0 in the finished workspace |
| Human interventions | 0 for fully automated runs; N passed via `--interventions N` for manual runs |
| Bloat lines | `git diff HEAD --stat` insertion count in workspace after the arm completes |
| Cost USD | `.total_cost_usd` from `claude --output-format json` |

## How to Run Once Unblocked

Prerequisites: `jq`, `claude` CLI authenticated, `node` + `npm` on PATH.
For the superx arm: `superx` binary on PATH or `SUPERX_BIN=/path/to/superx`.

```sh
# From the heimdall repo root:
cd evals/benchmark

# Dry-run — validates suite + prints execution plan, no models invoked:
bash harness.sh --dry

# Single arm, single task, one run (validate harness mechanics before full run):
bash run.sh --arm raw --task 01-multifile-feature --run 1 --confirm-spend

# Full 3x5x3 matrix (45 invocations, ~600k tokens):
bash harness.sh --confirm-spend

# Compute medians + print summary table:
bash summarize.sh

# Review results.jsonl (raw), summary.jsonl (medians), and this file.
```

Fill `model-pins.json` with actual model IDs before the full run.
Commit `results.jsonl`, `summary.jsonl`, and the filled copy of this file as one atomic commit.

## Honesty Rule

Every measured cell is published. If heimdall loses on tokens, wall time, or cost for a task,
those numbers appear in the table unchanged. A cheaper arm that ships fewer passing tests is not
winning; a slower arm that ships all tests is not losing. The numbers speak — no editing,
no hand-tuning, no cherry-picking runs.
